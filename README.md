# YellowPlanner Qt — отдельный проект

Это самостоятельная ветка приложения на PySide6. Старый проект YellowPlanner (Tkinter) не заменяется и продолжает собираться отдельно.

## Как создать новый GitHub-проект без установки Python на свой компьютер

1. Открой GitHub и нажми **New repository**.
2. Назови репозиторий, например `yellow-planner-qt`.
3. Выбери **Public** или **Private**, затем **Create repository**.
4. Загрузи в корень репозитория `YellowPlanner_Qt_1.0.py`, `requirements.txt` и `version_info.txt`.
5. Создай путь `.github/workflows/build-windows.yml` и вставь туда одноимённый файл из этого комплекта. Важно сохранить именно папки `.github` и `workflows`.
6. Нажми **Commit changes**.
7. Открой вкладку **Actions**. Должен появиться workflow **Build YellowPlanner Qt for Windows**.
8. Открой его, нажми **Run workflow** (либо дождись автоматического запуска после commit).
9. Дождись зелёной отметки успешного завершения. Внизу страницы запуска, в разделе **Artifacts**, скачай `YellowPlannerQt-Windows`.
10. Распакуй скачанный GitHub Artifact один раз. Внутри будет папка `YellowPlannerQt`; запускай `YellowPlannerQt.exe` из неё. Не вытаскивай EXE отдельно: рядом нужны `_internal` и остальные файлы.
11. В папке лежит `YellowPlannerQt.exe.sha256` — контрольная сумма EXE. Сверь её командой PowerShell: `Get-FileHash .\YellowPlannerQt.exe -Algorithm SHA256`.

Python устанавливается только на временном компьютере GitHub Actions. На твоём компьютере и на компьютере пользователя Python не нужен.

## Совместимость данных

Приложение читает и записывает `%APPDATA%\YellowPlanner\tasks.json`, как предыдущие версии. Перед первым запуском сделай копию этого файла и закрой старую программу. Не запускай две версии одновременно с одним файлом данных.

## Если браузер или Windows блокирует ZIP/EXE

- Этот workflow собирает **onedir**, не использует UPX и добавляет обычные сведения о версии файла. Это уменьшает некоторые эвристические срабатывания, но не гарантирует отсутствие предупреждений.
- GitHub Actions сам упаковывает папку артефакта в ZIP. Архив с EXE внутри всё равно может проверяться браузером или SmartScreen. Нельзя честно гарантировать, что антивирус перестанет его блокировать только после изменения имени или формата архива.
- Сверь SHA-256 EXE с `YellowPlannerQt.exe.sha256` командой PowerShell: `Get-FileHash .\YellowPlannerQt.exe -Algorithm SHA256`.
- Если Microsoft Defender или браузер продолжает считать файл вредоносным, отправь конкретный файл на проверку как false positive вендору антивируса. Не проси пользователей отключать защиту.
- Для устойчивого устранения предупреждений при публичном распространении нужен Authenticode-сертификат подписи кода. Подпись ставится на EXE после сборки, до упаковки ZIP; сертификат и секрет подписи хранятся в GitHub Secrets. Даже подпись не обещает мгновенную репутацию во всех браузерах и антивирусах.

## Состав

- `YellowPlanner_Qt_1.0.py` — приложение.
- `requirements.txt` — зависимости для сборки.
- `version_info.txt` — метаданные Windows EXE.
- `.github/workflows/build-windows.yml` — автоматическая сборка на GitHub Actions.
